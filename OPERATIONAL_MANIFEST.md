# AI Team System — Operational Manifest

## Core Identity

This project is NOT:
- an AGI platform
- an autonomous company
- a self-evolving AI kernel
- an enterprise orchestration framework
- a fully autonomous coding swarm

This project IS:
- a browser-first AI engineering mentorship workspace
- a local-first educational platform
- a guided engineering environment
- a human-controlled AI team simulation
- a practical learning + creation system

## Architecture Status

**COMPLETE.** 18 phases done. 949 tests. 91 modules. ~21k LOC.

No new architectural subsystems unless absolutely necessary.

## Current Priority: EDUCATIONAL EXPERIENCE RECONSTRUCTION

The runtime exists. Now improve:
- UX (buttons, tabs, modals, flows)
- Onboarding (conversational, not system-dump)
- Agent personalities (distinct, educational, human)
- Prompt Master (core feature — help structure thoughts)
- Runtime invisibility (beginners shouldn't see complexity)
- Repo-based learning (explain WHY, not just do)

## Critical Rules

NEVER:
- introduce AGI behavior
- introduce recursive self-improvement
- introduce hidden automation
- add enterprise SaaS architecture
- add cloud dependency
- add self-modifying systems

ALWAYS:
- preserve human approval
- preserve explainability
- preserve educational accessibility
- preserve local-first operation
- preserve browser-first UX
- preserve deterministic behavior

## Workflow for All Tasks

1. Understand user-facing problem
2. Identify type (UX, educational, runtime, architecture, state, frontend)
3. Prefer smallest coherent fix
4. Explain WHY the issue existed
5. Implement fix
6. Test manually
7. Run automated tests
8. Verify educational experience improved

## Mindset

Optimize for: clarity, trust, learning, maintainability, usability, calmness, survivability, educational value.

NOT for: maximum autonomy, complexity, abstraction, sophistication.

## Final Principle

AI Team System is not trying to replace engineers.
It is trying to help humans become engineers.
