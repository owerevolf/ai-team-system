# 🤖 AI Team System

Локальная мультиагентная платформа: команда ИИ-агентов собирает проект вместе с тобой, **а решения остаются за человеком**.

Ты пишешь идею в чат — TeamLead её разбирает, команда (Architect, Backend, Frontend, DevOps, Tester, Docs) предлагает план и готовит файлы. **Ничего не записывается на диск молча:** каждая правка приходит в панель «Подтверждения», где ты нажимаешь «Применить» или «Отклонить».

Проект задуман как **обучающий**: у него есть уровни объяснения (от «знания — ноль» до «только суть»), словарь терминов и Тур по системе.

---

## Быстрый старт (Windows)

**Двойной клик** по ярлыку «AI Team System» на рабочем столе — или:

```
start_windows.cmd
```

Скрипт сам поднимет окружение, проверит Ollama, запустит сервер и откроет браузер. Ничего вводить не нужно.

Вручную:

```powershell
cd "путь к проекту"
.\.venv\Scripts\python.exe -m uvicorn web_ui.app:app --host 127.0.0.1 --port 8000
```

**Требования:** Python 3.10+, [Ollama](https://ollama.com) с локальной моделью (`qwen3:8b` — проверенная). Интернет, VPN и платные подписки не нужны.

## Что ещё экспериментальное (честно)

- **Живой прогон сборки проекта на локальной модели** пока не выполнен: цепочка покрыта тестами, но полный сценарий «создать проект → подтвердить → применить» на `qwen3:8b` ещё не проходили. Это следующая задача.
- Генерация патчей моделью включается только при подключённой модели; по умолчанию работает упрощённый путь — он сохранён, чтобы не ломать живую сборку.
- Облачные провайдеры без ключа возвращают «нет ключа» — по умолчанию всё локально.
- Часть модулей governed execution (repo API, старые шаблоны) — наследие, к живому интерфейсу не подключена.

## Безопасность

- Терминальные маршруты выключены по умолчанию (`AITEAM_DEV_EXEC`, 403).
- CORS ограничен списком (`AITEAM_ALLOWED_ORIGINS`), сервер слушает `127.0.0.1` (`AITEAM_HOST`).
- **Секреты только в `.env`** — в репозитории им не место.
