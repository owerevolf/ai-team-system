# Карта проекта AI Team System

**Что это:** локальная (браузер-first) учебная мультиагентная платформа — чат с командой
ИИ-специалистов, режим обучения «Тур», конструктор промптов, канбан и заготовка
«управляемого исполнения» (патчи + подтверждения).

**Составлено:** 14.10.2026 по итогам сквозного чтения кода (не по документации).
**Точка отсчёта:** ветка `main`, коммит `071a95a` + правки этой сессии.

## 3. Тур (учебная часть) — как он устроен сейчас

- Кнопка «Как это работает (Тур)» (`welcome.html:20`) → `startChat('tour')` (`welcome.js:95`)
  → `startTour()` (`welcome.js:202`) → 9 шагов `TOUR_STEPS` (`welcome.js:112-200`) → выбор уровня (`:255-267`).
- Всё это **только во фронтенде**: заготовленный текст, без обращения к модели и к серверу.
- В Python лежит «второй Тур» — `core/learning_mode.py` (5 шагов), он мёртв (вызывается только тестами).
  README при этом описывает именно его — то есть документация рассказывает не о том Туре, который живёт.
- Уровни сложности (`zero/beginner/standard/advanced`) на Тур не влияют.

## 4. Источник правды (Project Brain)

- Реализован: `core/project_manager/runtime/developer/project_brain.py`, `brain_store.py`.
  Хранит цели, задачи, решения, ограничения, риски; персистентность — JSON в `.ai-team/brains/<project_id>/`.
- **В живом потоке пишет пустышку:** `.ai-team/brains/default/brain.json` — все списки пустые,
  заполнены только метки времени и `runtime_state: "idle"`.
- UI его не читает: 18 эндпоинтов `/api/developer/*` существуют, но фронтенд зовёт только
  `/message` и `/orchestrate`. Лозунг «All agents read from ProjectBrain» живыми вызовами не подтверждается.

## 5. Суб-агенты и промпты

- Реестр: `agent_registry.py` — 7 ролей (teamlead, architect, backend, frontend, devops, tester, documentalist)
  с правами и уровнями риска.
- `prompt_architect` живёт отдельно (свой модуль и роуты). `repo_explorer` существует **только как промпты**
  и строка в мёртвом `repo_endpoints.py` — модуля нет.
- Промптов 39: `prompts/roles/` — 34 файла (7 ролей × 4 уровня + вспомогательные), корень `prompts/` — 5.
- Путь промпта в модель один: `AgentManager.get_agent_prompt` (`:201`) → `run_agent` (`:231`) → `model_router.generate` (`:356`).
- **Уровни частично фиктивны:** `prompts/roles/<role>.md` побайтово совпадает с `<role>_advanced.md`;
  английские скиллы `core/skills/*` подгружаются только на уровне `advanced`.
- **Баг:** `beginner_mode` в `model_router.py` не меняет промпт — влияет только на хэш кэша (`:282-284`)
  и метаданные (`:597`).

## 6. Мультиязычность — что уже есть и что мешает

- Есть `core/i18n.py`: словари `ru`/`en`, функция `t()` (`:144`), эндпоинты `/api/i18n`, `/api/i18n/languages` (`app.py:1256-1270`).
- **Но:** фронтенд `t()` не вызывает, `/api/i18n` не дёргает, переключателя языка нет, каталог `config/i18n/` пуст.
- Зашитый русский текст: `welcome.js` — ~6 700 знаков, `welcome.html` — ~2 600, плюс строки в Python
  (`app.py:483-491`, `:277`) и все промпты ролей.
- Вывод: каркас двуязычности есть, но фактически язык один — русский (UI) при частично английских промптах.

| Полноценное проектирование проекта | Есть чат и создание файлов; настоящего конвейера «план → задача → патч → ревью → применение» нет |

| Наглядно: кто что делает и как зависит команда | Слабо: 7 чипов, плоский список шагов, зависимостей не видно, статусы не живые |

## 9. Предлагаемый порядок работ

1. **Быстрые победы.** Починить `beginner_mode` (уровни должны реально менять промпт), убрать дубли
   уровней (`<role>.md` = `_advanced.md`), привести README к фактам, пометить или убрать мёртвые роуты и страницы.
2. **Учебная полка.** Подключить i18n (ru/en → каркас на N языков), вынести тексты Тура из `welcome.js`
   в ресурсы, научить Тур объяснять на живом примере через выбранную модель.
3. **Связать команду с делом.** Довести живой поток до «план → задача → агент → патч → подтверждение → применение»,
   подключив уже написанный (и покрытый тестами) стек `patch_engine` + `approval_runtime` + `workspace_runtime`.
4. **Наглядность.** Граф зависимостей агентов и живой таймлайн (данные для событий уже есть в рантайме).
