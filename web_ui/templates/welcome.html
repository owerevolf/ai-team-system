📖 Инструкция по настройке

Пошаговый гайд как подключить бесплатные AI модели к AI Team System.

1Выбери провайдера

Мы рекомендуем OpenRouter — это единый API для 100+ моделей. Многие модели бесплатные!

🔗 Зарегистрироваться на OpenRouter

2Получи API ключ

После регистрации перейди в раздел Keys и создай новый API ключ.

🔗 Создать API ключ OpenRouter

Скопируй ключ — он начинается с sk-or-v1-...

3Вставь ключ в настройки

Перейди во вкладку ⚙️ Настройки, выбери OpenRouter и вставь API ключ.

Нажми 💾 Сохранить и подожди перезапуска сервера.

4Выбери модели для агентов

Система автоматически подберёт лучшие бесплатные модели, но ты можешь выбрать вручную:

  • TeamLead — рекомендуем deepseek/deepseek-r1:free (рассуждения)
  • Architect — рекомендуем openrouter/owl-alpha (1M контекст)
  • Backend — рекомендуем qwen/qwen3-coder:free (код)
  • Frontend — рекомендуем google/gemini-2.0-flash:free (быстро)
  • DevOps — рекомендуем meta-llama/llama-3.3-70b:free
  • Tester — рекомендуем qwen/qwen3-coder:free (код)
  • Documentalist — рекомендуем google/gemini-2.0-flash:free

5Альтернативные провайдеры

Если OpenRouter недоступен, можно использовать:

🔗 Ollama — локальные модели (полностью бесплатно, работает оффлайн)

🔗 OmniRoute — российский агрегатор AI моделей

6Проверь подключение

После сохранения настроек нажми 🔄 Проверить подключение в настройках.

Если всё работает — статус провайдера станет зелёным ✅
